🔒 Demo Security Module

Halaman ini sudah otomatis diamankan hanya dengan 2 baris:

<script src="security/security-config.js"></script>
<script src="security/security-core.js"></script>

✅ Coba test proteksi berikut:

  1. Tekan F12 atau Ctrl+Shift+I → muncul warning (tidak destroy aplikasi)
  2. Diamkan halaman ini 15 menit → auto-logout (warning 1 menit sebelumnya)
  3. Buka halaman ini di tab baru → tab kedua akan logout (single session)
  4. Buka halaman ini tanpa referrer (bookmark) → redirect ke https://mukminnasri.com/
  5. Tutup koneksi internet lalu kembali → jika sesi invalid, logout

⚠️ URL Parameter untuk Testing

  • ?from=main — simulasi akses dari mukminnasri.com (skip entry guard)
  • ?sec.bypass=1 — bypass entry guard sekali ini
  • Set SUPPRESS_IN_DEV: true di config untuk matikan seluruh modul

📦 Konfigurasi Default

  • Entry Guard: akses pertama WAJIB dari mukminnasri.com
  • Idle timeout: 15 menit + warning 1 menit sebelum
  • Session check: setiap 60 detik (Supabase jika ada)
  • Single session: tab kedua → logout
  • DevTools: WARNING (tidak destroy)
  • Tab heartbeat: setiap 5 detik
  • Tamper check: setiap 60 detik
  • Redirect target: https://mukminnasri.com/

🎨 Override Konfigurasi

Edit security/security-config.js. Contoh:

window.SECURITY_CONFIG = Object.freeze({
  REDIRECT_URL: "https://mukminnasri.com/",
  IDLE_TIMEOUT: 15 * 60 * 1000,         // 15 menit
  DEVTOOLS_ACTION: "WARNING",           // atau "LOGOUT"
  ENABLE_SINGLE_SESSION: true,
  ENABLE_ENTRY_GUARD: true,
  // ...
});
